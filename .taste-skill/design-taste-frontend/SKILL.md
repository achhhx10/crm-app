# Taste Skill: CRM Prospection App
DESIGN_VARIANCE: 3 | MOTION_INTENSITY: 2 | VISUAL_DENSITY: 8
## Design Read
CRM data-dense dashboard for 1-3 prospecteurs, minimal Linear-style, Tailwind + shadcn/ui, off-black dark mode WCAG AA.
## Rules
- shadcn/ui + Tailwind v4 tokens + dark: (already installed)
- Max 1 accent color (amber/gold accent on navy base)
- Off-black (no pure #000), off-white (no pure #fff)
- Dense data layout (p-4, gap-3, text-sm) — not airy
- Cards only when elevation communicates hierarchy
- No 3-equal-cards. No AI purple gradients. No em-dashes.
- Button tactile: scale-[0.98] on :active, focus-visible ring
- Skeleton loading (no generic spinners)
- Consistent border-radius (0.5rem lg)
